# Authority Boundary

This repository is executable authority for the broad PA model benchmark: source, tests, synthetic fixtures, prompt-guide snapshots, manifests, and generated local artifacts.

Human decisions, PA benchmark interpretation, routing reports, and the PA benchmark index remain in a separate decision/report authority (e.g., a project management system or knowledge base). Every decision-grade report must bind the exact repository commit/tree, run ID, artifact path, model route/identity, repeat depth, and material hashes.

A separate coding-benchmark project owns coding-specific evaluation. Methods may be adapted into this repository, but coding scores, fixtures, hidden tests, reports, and promotion decisions are not PA evidence.

No report or passing suite mutates PA routing automatically. Local Ollama and Ollama Cloud are separate decision categories; this programme names one eligible leader per category or explicitly reports that no candidate qualifies.
